[колесо прокрутки мыши вперед] увеличить масштаб
<ctrl> + <курсор вниз> уменьшить масштаб

<ctrl> + <курсов влево> предыдущий источник карты
<ctrl> + <курсор вправо> следующий источник карты
[тащить левой кнопкой мыши] выделить область для загрузки
